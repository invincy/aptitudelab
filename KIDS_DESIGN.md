# Kids Lab shared design

Build every new topic inside the existing shell, using kids-app-shell.css. Keep the purple, mint and sunshine palette, rounded activity cards, star feedback and common buttons. Add an activity renderer and bilingual content rather than a new page or theme.

## The learning journey

- Play: one instruction, a visible manipulation, a short result. Fold number settings into Change the numbers.
- Understand: explain why the manipulation works and invite the child to explain it with objects.
- Try: five short challenges, immediate explanations, gentle retries and a completion celebration.

For questions containing countable objects, instruct the child to touch first. Each object accepts one touch and displays its counting order. Unlock choices only after all objects have been counted. Hints before completion teach the action rather than reveal the final number. Preserve touched state when changing language or selecting an answer.

## Small screens first

Use a fixed header and bottom navigation with one central content area. The adventure shelf contains at most four cards; use Back / More adventures and stage filters. Keep normal counting and home screens within a phone viewport. Dense mathematical models, expanded controls, large text and grown-up guidance can scroll locally so content remains accessible; never clip explanations to force a fixed height.

Use at least 48px for primary touch objects, visible keyboard focus, text alongside icons, both English and Hindi, and reduced-motion support. Keep teaching view on the same renderer and styling system.
